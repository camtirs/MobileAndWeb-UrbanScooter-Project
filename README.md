# 🛴 Urban Scooter - API, Mobile & Web Quality Assurance Testing Project

My Sprint project from the TripleTen QA Engineer. The project focused on analyzing, testing, and validating the functionality of **Urban Scooter**, a web application for electric scooter rentals.

## 🎯 Project Overview

The main objective was to assess application quality through functional testing, UI validation, and API testing, applying software testing methodologies and documenting identified defects.

Key activities included:

- Reviewing and analyzing functional requirements.
- Designing test cases using equivalence partitioning and boundary value analysis.
- Performing UI and functional testing.
- Validating API endpoints using Postman and Chrome DevTools.
- Identifying, documenting, and reporting software defects.

## 🛠️ Tools & Technologies

- **Postman:** API testing and endpoint validation.
- **Chrome DevTools:** Network inspection and request validation.
- **Draw.io:** Mind maps and workflow documentation.
- **Microsoft Excel:** Test case design and test result tracking.
- **Git & GitHub:** Version control and project documentation.

## 📂 Repository Structure

- **Mind Map:** Visual representation of the order placement workflow.
- **Test Cases:** Test scenarios based on equivalence partitioning.
- **Evidence:** Screenshots and supporting test documentation.
- **PDF Documents:** Functional requirements and evaluation criteria.
- **Excel Files:** Test analysis, test cases, and execution results.
